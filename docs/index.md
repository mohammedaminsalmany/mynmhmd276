# Welcome to Doca

**Doca** turns a folder of Markdown files into a fast, modern documentation
site — with full-text search, a collapsible sidebar, automatic tables of
contents and a dark/light theme, using nothing but the Python standard library.

```bash
git clone https://github.com/mohammedaminsalmany/doca.git
cd doca && pip install -e .
doca init my-docs
cd my-docs
doca serve
```

## Why Doca?

- **Zero dependencies.** The base engine runs on Python 3.10+ with no third-party packages.
- **Fast.** A typical site builds in milliseconds; there is no bundler and no watcher overhead.
- **Portable.** The output is plain HTML, CSS and a few lines of vanilla JavaScript.
- **Self-contained.** Every page ships its own styles — no CDN, no external fonts, no lock-in.
- **Developer-first.** Front matter, nested navigation, syntax-labelled code blocks and one-command preview.

## Features

| Feature | What it does |
| --- | --- |
| Markdown engine | Headings, lists, tables, code blocks, quotes and inline formatting |
| Auto TOC | A nested "On this page" outline generated from your headings |
| Search | Client-side full-text search across every page, without a server |
| Navigation | Explicit groups in `doca.json`, or automatic generation from your files |
| Theming | Light, dark or follow the reader's system preference |
| Live preview | `doca serve` rebuilds the site whenever a file changes |

## How it works

Doca reads your Markdown, renders it to HTML and wraps it in a responsive
layout. One configuration file controls the site title, theme, navigation and
footer.

```text
my-docs/
├── doca.json          # site configuration
├── docs/              # your Markdown sources
│   ├── index.md
│   ├── getting-started.md
│   └── configuration.md
└── site/              # generated by `doca build`
```
